# Dataset Source

WELFake dataset landing page: https://zenodo.org/records/4561253
Direct download used by notebook: https://zenodo.org/records/4561253/files/WELFake_Dataset.csv?download=1

The dataset documentation reports 72,134 accessible articles, 35,028 real and 37,106 fake. Labels are 0=fake and 1=real.

The notebook downloads the CSV automatically when it is not present.
